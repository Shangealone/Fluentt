# Public FIFAKT-derived development validation v2

Protocol frozen before this run's model fitting or held-out evaluation, 2026-11-05.

This is an independently implemented, reduced-size FIFAKT-derived public-data model, using the existing reviewed `PublicPilotModel`. It is not a paper reproduction, a FLUENTT format-aware predictor or evidence of retention benefit. The upstream architecture/source reference is BoxuanMa/FIFAKT at a03e248141fc32a96dc6fda3bb6ae52be621bb9a; retain UPSTREAM_FIFAKT_LICENSE.txt. Data are Settles and Meeder (2016), DOI 10.7910/DVN/N8XJME, publisher CC BY-NC 4.0. No embeddings or external checkpoint are downloaded. Every produced bundle has research_ready=false and a prediction contract different from the live provider contract.

## Frozen experiment

- Verified 379,004,009-byte gzip corpus, publisher MD5 and local SHA-256 required. Read at most the first 2,000,000 rows, first 6,000 English learners, at most 96 encounters each. This is bounded prefix sampling, not a representative corpus benchmark. Retain up to eight last eligible prediction examples per learner, with up to 24 strictly earlier encounters. Same-timestamp history is excluded.
- Use the historical pilot's salted hash (`fluentt-public-pilot-v1:`) and bucket modulo ten: 0–6 training, 7 calibration, 8 validation/model selection, 9 final test. Thus historical pilot validation and reserved test buckets do not move into training. Calibration bucket 7 was historically part of the pilot's training bucket; it is disjoint from training in this new experiment, but is not independent of prior architecture exploration. The final test bucket was reserved and not evaluated by the documented historical pilot.
- Word/item mappings and six-feature standardization fit training only; padding=0, unknown=1. Features and model architecture remain those documented in PUBLIC_PILOT.md: 32/16 learned embeddings, hidden size 32, history LSTM and candidate attention. No question-format input, Tagalog training or pretrained semantics is fabricated. Target is observed session recall proportion, not a binary answer or forecast at an arbitrary requested future horizon. Prior source history counts are consumed as published; current session counts never become input.
- Three seeds: 20261105, 20261106, 20261107. Each fits at most 800 Adam steps, learning rate .001, batch 32, two CPU threads, deterministic algorithms. Clip gradient norm at 1. Check finite losses, gradients and weights. Validate every 100 steps on all retained validation examples; retain the checkpoint with minimum validation MAE, including the untrained initial state. Select seed by that same metric. Maximum 180 seconds optimization per seed; total worker supervisor deadline 900 seconds; 3 GiB peak resident process budget and minimum 4 GiB available memory before training. No speech weights load.
- Calibration uses only bucket 7: fit positive-temperature plus intercept to selected model logits by soft-target binary cross entropy, at most 200 Adam steps. Choose fitted transform only if calibration BCE improves over identity. Bound log-temperature [-3,3], intercept [-5,5]. Freeze selection/transform before final-test inference.
- Baselines fit training candidates only: global mean and per-lexeme empirical mean (global mean for unseen lexemes). No FSRS superiority claim: this dataset's session outcomes do not supply the app's subjective recall ratings, so do not fabricate them to compare schedules.
- Final evaluation: MAE, RMSE and soft-target BCE, descriptive binned prediction-versus-mean-recall gap, OOV rates, per-learner MAE and paired model-minus-baseline MAE. Report 95% percentile intervals from 500 learner-cluster bootstrap samples, with fixed seed 20261105. These are descriptive uncertainty for this bounded cohort, not an intervention-effect estimate. Learner IDs remain private; exported sample keys are hashes of source-file identity plus row ordinal. Public report contains aggregates only.
- A preliminary predictive PASS requires finite held-out outputs, zero split leakage, exact checkpoint round trip, and paired MAE intervals entirely below zero against **both** baselines. Otherwise report PARTIAL/FAIL without retuning against this test set. Deployment remains BLOCKED regardless of public benchmark outcome because format coverage, horizon calibration, local population validation and participant workflow are absent. No academic accuracy percentage or treatment benefit is inferred.

## Reproduction

From the redesigned app folder, use an isolated Python 3.12 CPU environment with Torch 2.11.0+cpu and psutil 7.2.2. New version relative to the historical pilot is recorded, not claimed identical.

1. Run `download_public_data.py` (or reuse its verified corpus).
2. Run `development_validation_tests.py` and the existing `public_pilot_tests.py` in that environment.
3. Run `run_development_validation.py --output <new-ignored-directory>`. It refuses an existing output directory and enforces resources/deadline.
4. Keep manifest, source/protocol hashes, model checkpoint, selection/calibration record, results, private predictions and execution log together. Do not run another selection against the same test outcomes. This is not consumed by the production API.
