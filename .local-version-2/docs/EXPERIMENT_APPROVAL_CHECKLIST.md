# Experiment approval checklist

2026-11-05. Documentation-only audit. VERIFIED = source/artifact observation; PROPOSED = requires approval; BLOCKED = unmet prerequisite. No application/schema/configuration/participant changes. Existing uncommitted work preserved. No live database inspected; statements about behavior describe code, not actual enrollment counts.


All items PENDING/PROPOSED unless external evidence is later verified. No approval is inferred from a code flag, repository note or this report.

- Adviser/research team: choose parallel 15/15 versus within-learner pool comparison; approve revised objectives, unit of randomization, primary estimand, sample/precision justification and analysis plan. Retain superseded counterbalanced protocol as history.
- Institution/site/client and relevant ethics review body: determine required review and approve revised procedure before recruitment/treatment. This audit does not make a legal/ethics exemption determination.
- Participant protection: age-appropriate information sheets, voluntary informed consent, assent and guardian permission where institutionally required for minors; no grade/access penalty for refusal; withdrawal and permitted post-withdrawal data use; accessible contacts and complaints route.
- Research/privacy operators: coded identity separation, authorized re-identification, access/logging, storage/retention/deletion, permitted model-training use and any external processor disclosures; no training reuse of formal study data by assumption.
- Allocation: roster eligibility, concealed generation/custody, approved stratification, assignment freeze/replay, late enrollment, withdrawal/replacement and deviation reporting; preserve existing classes/join codes.
- Teaching/instruments: common pinned materials, comparable objectives, identical non-scheduling feature access, instructor conduct, outside exposure/contamination policy, pretest/posttest/delayed forms/scoring/feedback and incomplete-assessment rules.
- Calendar/burden: exact month dates/timezone, weekday/holiday rules, active-day windows, midnight in-flight work, no-due/missed/catch-up policy, 5–10 minute feasibility and seven-day assessment anchor/windows.
- Model/governance: compatible format/horizon features, mappings, permissions, sealed validation/calibration, readiness criteria, fallback/low-coverage handling and independent sign-off. Development checkpoint remains BLOCKED FOR LIVE USE.
- Implementation/deployment: approve new versioned schema/contracts and staged migration plan separately; disposable tests, authorized shadow replay, device checks, permission revocation and operational rollback before operator activation. This audit authorizes none of these changes.

Decision record should include named approver/role, dated evidence reference, approved protocol hash/version, scope and revocation/supersession. Never fabricate approval ledger rows to clear blockers. Present this checklist with PARALLEL_GROUP_PROPOSED_SPEC.md for actual decisions.
