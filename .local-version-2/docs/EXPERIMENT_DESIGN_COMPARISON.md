# Experimental design comparison

2026-11-05. Documentation-only audit. VERIFIED = source/artifact observation; PROPOSED = requires approval; BLOCKED = unmet prerequisite. No application/schema/configuration/participant changes. Existing uncommitted work preserved. No live database inspected; statements about behavior describe code, not actual enrollment counts.


| Dimension | VERIFIED current ESR foundation | PROPOSED 15/15 parallel design |
|---|---|---|
| Assignment unit | Person randomized to pool mapping; both conditions per person | Person randomized once to one algorithm |
| Content | Two disjoint pools; equivalence and mapping effects matter | Same pinned vocabulary/objectives/assessment rules available to both arms |
| Time | Both algorithms during one period; no switch | One assigned algorithm throughout one intervention |
| Baseline equivalence | Pairing controls stable learner differences; pool baselines still needed | Chance imbalance is plausible at n=15/arm; pretest and prespecified adjustment |
| Carryover | No period crossover carryover, but cross-pool learning/strategy transfer and fatigue possible | No within-person algorithm exposure by design; peer/outside-practice contamination remains |
| Exposure | Need balanced opportunities/order between pools without forcing equal due queues | Algorithm-driven differences allowed, measured as possible treatment mechanisms |
| Validity | Efficient within-person contrast if pool matching and spillover controlled | More direct whole-system algorithm-policy effect if all other features comparable |
| Analysis | Repeated learner outcomes plus pool/mapping/item effects | Between-arm baseline-adjusted outcome, not treating repeated reviews as independent students |
| Complexity | Pool matching, within-session order, within-person dependence | Concealed allocation, between-arm balance, new protocol/schema and day/assessment machinery |
| Burden | Both pools compete for each person's brief session | One condition per person; brief daily target remains to be piloted |
| Small sample | Potential efficiency from pairing; cannot claim adequate power without inputs | Simpler estimand but 15/arm yields potentially wide intervals and sensitivity to attrition |

PROPOSED recommendation: adopt parallel assignment if the approved thesis question is the effect of assigning the entire classroom review policy FSRS-6 versus FSRS-6+FIFAKT. It fits the newly stated methodology and avoids mixing both schedulers within each learner. It is not intrinsically scientifically superior: current within-person design could suit a different, carefully controlled item-set contrast and may use a small cohort efficiently. Final choice requires adviser approval, precision/power assumptions and an explicit estimand before code conversion. The earlier counterbalanced design approval is retained historical provenance, not authorization for the new design.

Do not confuse three evidence layers: historical model prediction errors; offline proposed-schedule mechanics; future randomized vocabulary outcomes. None substitutes for another. Keep interface, pronunciation, Tutor access, instructor support, vocabulary and assessments comparable; log relevant outside exposure only under the approved privacy protocol. Forbid unapproved group-specific tutoring/content and identify peer sharing as a contamination risk.
