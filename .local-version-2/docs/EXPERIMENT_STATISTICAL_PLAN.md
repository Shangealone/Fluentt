# Proposed statistical analysis plan

2026-11-05. Documentation-only audit. VERIFIED = source/artifact observation; PROPOSED = requires approval; BLOCKED = unmet prerequisite. No application/schema/configuration/participant changes. Existing uncommitted work preserved. No live database inspected; statements about behavior describe code, not actual enrollment counts.


PROPOSED, pending adviser/statistician sign-off and instrument/power justification. No statistical student results were calculated.

Primary estimand: effect of random assignment to the hybrid review policy versus FSRS-6 among the randomized eligible cohort on the common seven-day delayed vocabulary outcome, including real fallback behavior under each assigned policy. Define scoring scale, denominator, equivalent-form linking, timing anchor/window, target population and protocol deviations before enrollment. Use participant-level delayed total (or prespecified valid comparable scale), not average review correctness across personalized queues.

Recommend a parsimonious ANCOVA: delayed outcome = intercept + assigned arm + baseline vocabulary score. Include only necessary prespecified randomization strata where identifiable; never add many post-hoc covariates for n=30. Report adjusted arm difference in original score units with a 95% interval and exact sample counts. Examine bounded-score/ceiling and residual assumptions; predefine robust small-sample or randomization-based sensitivity methods under the actual randomization procedure. A generic permutation of participants is not valid if it ignores the implemented constrained/stratified assignment scheme.

Baseline-adjusted analysis can improve precision over unadjusted/change-score comparisons when appropriate; see [Vickers and Altman, BMJ 2001](https://www.bmj.com/content/323/7321/1123). This recommendation is conditional on instrument properties and assumptions, not a guarantee with 15 per arm. Provide baseline summaries, not significance tests to decide randomization success. Standardized Hedges-type effect sizes may supplement original-unit differences; specify their denominator and small-sample correction, with uncertainty.

Secondary outcomes: immediate posttest (similarly baseline-adjusted), delayed-versus-immediate loss, adherence, exposure, fallback coverage and technical usability. Prespecify one primary test, two-sided alpha proposal .05 and whether secondary comparisons use Holm correction or are explicitly exploratory; final choices require approval. Repeated item/review observations are nested within learners, not thousands of independent experimental subjects. Item-level mixed models are optional sensitivity work only if sample/data support them. The existing within-learner pool design instead needs paired/multilevel analysis including pool/mapping effects, so its analysis is not interchangeable.

Primary analysis should follow randomized assignment, documenting all randomized participants and missing outcomes. Do not automatically count missing/withdrawn assessments as zero, carry forward a score, exclude low adherers, or rerandomize to restore 15 completers. Record why/when each observation is absent and permitted follow-up after withdrawal. Prespecify a realistic missing-data strategy and sensitivity range; multiple imputation is not automatically reliable with 30 learners. Complete-case results, if reported, must disclose loss of randomization balance and plausible missingness bias. No conditional-on-completers superiority claim. Per-protocol estimates, if any, are exploratory.

Exposure and model fallback are post-randomization mechanisms: describe their distributions without adjusting them out of the primary total-policy effect. Equal materials/opportunity do not imply identical review counts. If learners span multiple instructors/classes, randomize within appropriate approved strata or acknowledge clustering/confounding; two intact classes cannot establish a clean student-randomized algorithm effect merely by assigning one class to each arm.

Thirty is a planned enrollment target. Specify minimum meaningful score difference and plausible variance/baseline correlation/attrition to justify power or expected precision before claiming adequacy. If not defensible, present a feasibility/pilot interpretation and wide intervals. No power or significance number was invented.

Keep three analyses distinct: saved historical prediction MAE/log loss/calibration on public data; offline interval/fallback mechanics; future randomized retention outcomes. The first two cannot establish a treatment benefit. Preregister before allocation and freeze analysis before unblinding outcomes. [CONSORT 2025 explanation](https://www.bmj.com/content/bmj/389/bmj-2024-081124.full.pdf) supports documenting sequence generation/concealment; it is used as a reporting reference, not as proof this educational study has approvals.
